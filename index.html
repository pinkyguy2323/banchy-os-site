Built as its own system

Inspired by ideas from Omarchy, but a different architecture underneath: its own CLI, theme engine, boot system and installer — designed to stay fast and predictable for years.

Banchy CLI

One tool for the whole system. Update, diagnose, theme, profile and backup from a single predictable command surface.

  • banchy update
  • banchy doctor
  • banchy theme set midnight
  • banchy profile developer
  • banchy config backup

Theme Engine

Five themes, one command. banchy theme set re-themes Hyprland, Waybar, terminal, launcher, notifications and wallpaper as a single atomic step.

  • Midnight
  • Black
  • Frost
  • Neon
  • Minimal

Banchy Settings

A GUI for theme, accent color, blur, transparency, gaps, animations, wallpapers, fonts and monitors. Every value is validated and a bad change rolls back automatically.

  • Validated
  • Automatic rollback

Banchy Boot

A systemd-boot based bootloader with Start Banchy OS, Previous Kernel and Recovery Mode. Boot safety checks run every time, and a failed update rolls back on its own.

  • systemd-boot
  • Auto rollback

Safe updates

Pre-flight checks for network, disk, pacman and bootloader, config backups, Btrfs snapshots and post-update verification — before you ever see a broken system.

  • Pre-flight
  • Btrfs
  • Verification

Package profiles

Minimal, Default, Developer, Creator, Gaming and Full. Choose one during install or switch later — the set is added and removed coherently, never piece by piece.

  • Minimal
  • Default
  • Developer
  • Creator
  • Gaming
  • Full

Banchy Installer

A guided TUI installer with ext4 or Btrfs, GPT + UEFI, sensible defaults and automatic post-install verification of the whole system.

  • ext4
  • Btrfs
  • GPT + UEFI

Recovery Mode

Filesystem check, bootloader repair, initramfs regeneration, config restore and a root shell — reachable straight from the boot menu, no live USB needed.

  • fsck
  • initramfs
  • Root shell

Theme engine

Five themes. One command.

Each theme touches every surface of the desktop at once — and every change is applied as one transaction, so your session never ends up half-styled.

Banchy Midnight

banchy theme set midnight

Deep blue-black surfaces with a calm indigo accent.

Banchy Black

banchy theme set black

True black OLED-friendly theme, almost no color at all.

Banchy Frost

banchy theme set frost

Cool slate blues with a glacial cyan accent.

Banchy Neon

banchy theme set neon

High-energy green on near-black, built to glow.

Banchy Minimal

banchy theme set minimal

Pure grayscale. Nothing between you and the work.

Stability principle

Validation + Backup + Fallback + Rollback for every critical change.

Never beauty at the cost of stability.
